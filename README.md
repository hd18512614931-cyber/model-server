# 佛山年画 AI 创作小程序

这是一个基于微信小程序原生框架开发的工具，旨在结合传统木版年画工艺与现代 AI 图像分割技术，允许用户上传照片并将其拆分为经典的版画套印的多色图层（如红、黄、绿、紫、黑线稿），最终合成一张具有中国传统春节意蕴的数字“佛山年画”。

## 目录结构
```text
├── components/          # 自定义组件
│   └── layer-stack/     # 负责实现多图层真实叠印的相乘(multiply)预览组件
├── images/              # 图片资源目录（详见内部README）
├── pages/               # 页面模块
│   ├── index/           # 首页：展示轮播图与功能入口导航
│   ├── create/          # AI创作页：负责选取照片/拍照及触发分色上报
│   └── layers/          # 图层页：横向滚动展示分色层，叠加套印实时预览与保存
├── utils/               # 工具函数库
│   ├── api.js           # 封装的 Promise 网络请求及 Mock 模拟拦截
│   └── util.js          # 时间格式化、ID生成及 Base64 转换等业务通用函数
├── app.js               # 小程序逻辑入口及全局配置
├── app.json             # 小程序路由级及窗口底部导航（Tabbar）配置
└── app.wxss             # 小程序全局通用样式
```

## 核心功能说明
1. **作品画廊展厅（瀑布流）**：首屏向受众提供其他用户的经典创作作品浏览。
2. **一键转换 AI 分色**：用户唤起本地相册/相机，通过 Base64 原图提交至由 AI 支持的后端进行图像上色与多版分色。
3. **沉浸式木版叠印体验**：提取后端下发的PNG透明遮片，在前端组件内使用 `mix-blend-mode: multiply` 高保真模拟色彩叠底过程，支持随意显隐某一层探究上色奥秘。
4. **一键封排与分享**：可将套版上色后的成果经过 Canvas 重新合成，保存至相册或直接拉取微信好友分享。

## 使用指引

### 1. 导入微信开发者工具
1. 下载安装并打开 **微信开发者工具**。
2. 点击界面的 `+`（新建项目）或“导入项目”。
3. 在项目目录中选择 `foshan-nianhua-frontend` 文件夹。
4. 填写你在微信公众平台申请的 **AppID**（若无，可选择“测试号”使用基础功能）。
5. 点击“确定”完成导入。环境将自动编译，通常在左侧模拟器里就能直观看到成品首页了。

### 2. 配置后端 API URL 开关
在向后端发起大模型和后台通信前，通常需在通信工具层面调整连接配置。
请打开根目录下的 `app.js` 文件，查找到 `globalData` ，你会看到如下配置：
```javascript
globalData: {
  userInfo: null,
  apiBaseUrl: 'http://localhost:8000', // 这里更换为你的后端服务器实际地址
  useMock: true,                       // 【重要】开发调试时若没有后端，请保持为 true
  currentLayers: null
}
```
> **📝 注：** 当 `useMock` 为 true 时，调用 `/api/v1/separate` 的分色动作不会真实发送请求，而是延迟 1.5s 后下发虚拟彩层占位图以便你体验核心多层组件展现流程。如果您的后端已启动且连通，请将其置为 **false**。
