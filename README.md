# 佛山木版年画 AI 创作微信小程序

这是一个面向非遗数字化展示与互动体验的微信小程序项目。项目以佛山木版年画为主题，把 AI 图像生成、后端分色处理、五色套印交互和 2D/3D 展示结合起来，让用户可以从“生成一张年画”进一步看到它被拆分成不同色版后的叠印过程。

> 当前小程序仍在迭代中。正式上线后，这里会补充微信小程序码、体验链接或演示二维码。

## 项目定位

项目的核心目标不是只做一个展示页，而是把传统木版年画的“分版、上色、套印”过程做成可交互、可解释、可演示的数字体验。它既可以作为非遗传播作品，也可以作为我在实习面试中展示工程能力、AI 应用落地能力和 CI/CD 实践经验的项目。

## 我负责和实现的内容

- 微信小程序前端页面开发：包含首页叙事、五色套印互动、2D 分色展示、3D 展厅、AI 年画创作等模块。
- AI 生图链路：用户输入主题后，通过云函数调用图像生成能力，生成符合佛山木版年画风格的图片。
- 后端分色逻辑：对 AI 生成图进行颜色分离，输出透明 PNG 色彩图层，用于前端分层展示和套印模拟。
- 图层展示体验：支持把黑线、红色、黄色、深黄色、蓝色等色版逐层展示，模拟木版年画的套印过程。
- CloudBase 云开发集成：使用云函数、云存储承接 AI 生成图、分色图层和小程序端资源访问。
- GitHub Actions 与 CI/CD：围绕小程序项目配置自动化检查和部署流程，减少手动上传、重复构建和环境不一致的问题。

## 技术亮点

### 1. GitHub Actions 与 CI/CD

项目接入 GitHub Actions 作为自动化流水线，核心思路是把“提交代码、安装依赖、检查构建、生成预览、发布上传”等步骤标准化。

实现方式包括：

- 在代码推送或合并时触发 CI 流程，自动安装依赖并执行基础检查。
- 使用微信小程序相关构建工具，将本地小程序项目纳入自动化构建流程。
- 通过 GitHub Secrets 管理 AppID、上传密钥、CloudBase 环境等敏感配置，避免把密钥写进代码仓库。
- 区分开发预览和正式发布流程，便于后续生成预览二维码或自动上传版本。
- 将云函数和前端资源拆开管理，使 AI 生图、分色处理和页面展示可以独立迭代。

这部分的价值是让项目从“能在本地跑”进一步变成“可以持续维护、可以交付、可以协作”的工程项目。

### 2. AI 生成图片后的后端分色

项目的核心技术亮点是后端分色逻辑。用户通过 AI 生成一张年画后，系统会继续把图片拆成多个色彩图层，而不是只展示一张普通图片。

分色处理的大致流程：

1. 用户输入主题，小程序调用云函数生成 AI 年画。
2. 云函数将生成结果保存到 CloudBase 云存储，避免临时链接过期。
3. 后端对图片进行颜色分析和分层处理，识别黑线、红色、黄色、深黄色、蓝色等主要色版。
4. 每个色版输出为透明 PNG 图层，只保留对应颜色区域。
5. 小程序端读取这些图层，在 2D 展示页和套印交互中逐层叠加。

这个设计让 AI 生成结果不只是“看起来像年画”，而是进一步对应到传统木版年画的制作逻辑：一张完整图像可以被解释为多个独立色版的叠印结果。

### 3. 五色套印交互体验
<img width="1080" height="2374" alt="Screenshot_2026-05-27-21-12-51-89_e39d2c7de19156b0683cd93e8735f348" src="https://github.com/user-attachments/assets/6ea58d40-c0ba-408f-862d-3c2bf3ce6ad6" />

首页中的套印模块把色版做成可选择的“画板”。用户选择某个色版后，拖动纸张进行压印，页面会即时显示对应图层，模拟传统年画一版一版印上去的过程。

当前图层已经调整为：

- 黑色：线稿、轮廓和细节
- 红色：主体红底与红色色块
- 黄色：明亮装饰色
- 深黄色：文字、边框、木纹等厚重色
- 蓝色：蓝色与青蓝色块

这样可以避免红版混入黄色文字、蓝版混入黑线稿等问题，让色版展示更接近真实分色逻辑。

### 4. 小程序端工程实现

前端采用微信小程序原生开发，页面按功能拆分，配合通用工具函数处理云文件下载、图层保存、API 请求和页面跳转。

主要模块包括：

- `pages/home`：项目主叙事、工艺介绍、五色套印互动和更多体验入口。
- `pages/ai-create`：AI 年画创作入口，负责输入主题、调用生图云函数和触发分色。
- `pages/exploded-view`：分色图层的 2D 展示与拆解查看。
- `pages/gallery` 与 `pages/model3d-viewer`：3D 模型展厅与模型查看。
- `cloudfunctions/generateImage-RA7PaB`：AI 生图云函数，负责模型调用和结果入库。

## 项目价值

对工程实践来说，这个项目覆盖了小程序前端、云函数、云存储、AI 生成、图像分色、自动化 CI/CD 等多个环节，比较完整地体现了从功能开发到工程交付的能力。
